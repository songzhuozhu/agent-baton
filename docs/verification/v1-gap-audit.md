1. **部分完成**：macOS 实际 Electron 启动、macOS/Windows/Linux ARM64 目录构建成功；Windows/Linux 尚无真实桌面运行证据。三平台源码检查由 [GitHub Actions](https://github.com/songzhuozhu/agent-baton/actions/workflows/ci.yml) 执行，每版结果以对应提交的 CI 记录为准。
2. **部分完成**：本地来源与 Git 上游来源均可通过桌面端隔离预览后纳管，且更新实现已有 fixture 测试；缺真实 GitHub 远端上游实测。
3. **已覆盖**：端到端 fixture 验证同一 Skill 跨两个分组、无重复部署且 Local Only 未导出。
4. **已覆盖**：不同 Agent 状态、三态覆盖和批量选择多个 Agent 的分组分配已有确定性测试与桌面交互。
5. **已覆盖（fixture）**：预览、并发修改中止、单 Agent 原子回滚、最近应用撤销、批量独立结果汇总均有测试。

7. **已覆盖**：多层过滤和同步导出测试证明 Local Only 无法进入快照。
8. **部分完成**：三方合并冲突内核有测试；两台真实设备和冲突决议界面未完成。
9. **已覆盖（fixture）**：恢复只写托管库/期望状态且零 Installation；真实新设备待验证。
10. **已覆盖（fixture）**：隔离暂存、差异、分叉阻断、确认更新与备份有测试。

## 2026-09-19 打磨补充

本轮改动和剩余问题见[开发路线](../roadmap.md)。浏览器 fixture 已检查深浅主题、980 × 680 桌面布局、原生弹窗错误显示和 Escape 焦点返回；这不等同于完整 Electron 或真实 Agent 验收。

同步恢复现在以单一数据库事务提交实体与基线，并在确认前/事务内重新检查本地冲突。Git 提交限定便携目录，保留用户其它暂存内容；同步实体 ID 和文件名必须匹配，非法路径在写入前拒绝。

仍需优先修复多项 Undo 的失败补偿、Apply Plan 与实时发现结果不一致，以及直接 symlink 对托管内容生命周期的耦合。当前不能把首页数量提示或本轮测试通过解释为完整的漂移/重载证明。
