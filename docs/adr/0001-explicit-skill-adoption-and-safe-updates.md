# 显式纳管 Skill 并安全处理上游更新

AgentBaton 只读扫描 Agent 已安装的 Skill，只有用户明确纳管后才可能将其内容和独立元数据写入同步仓库，避免自动上传公司内部、系统内置或其他敏感内容。同步授权使用独立于自由 Tag 的固定策略：新纳管 Skill 默认为 `Local Only`，且该策略始终覆盖 Skill Group 的同步选择；只有 `Sync Allowed` 才可进入同步仓库。Skill Group 是否参与同步是持久设置，而不是每次同步时的临时选择。把已同步 Skill 改为 `Local Only` 只会在确认后从后续版本移除；V1 明确警告历史 Commit 仍可能保留内容，不自动重写 Git 历史或强制推送。上游来源 Skill 保留仓库地址、相对目录、最后同步 Commit 和内容摘要；检查更新不修改文件，V1 不自动合并或静默覆盖本地分叉，覆盖前必须由用户明确选择并创建可恢复备份，以换取可复现同步和数据安全。
